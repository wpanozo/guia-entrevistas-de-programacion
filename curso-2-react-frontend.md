# Curso 2: Frontend Avanzado con React

## 📋 Información General
- **Título**: "Maestría en React: Construye una App de Gestión de Tareas Profesional"
- **Duración**: 12 horas (48 videos)
- **Nivel**: Intermedio (requiere Curso 1)
- **Proyecto Principal**: TaskMaster Pro - Aplicación de Gestión de Tareas
- **Precio Sugerido**: $89.99

## 🎯 Objetivos de Aprendizaje

Al finalizar este curso, el estudiante será capaz de:
- ✅ Desarrollar SPAs completas con React 18
- ✅ Manejar estado global con Context API y useReducer
- ✅ Implementar routing y navegación con React Router
- ✅ Consumir APIs REST y manejar datos async
- ✅ Aplicar patrones de diseño y mejores prácticas
- ✅ Optimizar performance de aplicaciones React
