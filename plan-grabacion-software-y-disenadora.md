## 📝 RECOMENDACIONES ESPECÍFICAS PARA GRABACIÓN

### **🎥 Mejores Prácticas para Waldo:**

#### **Antes de Grabar:**
- [ ] **Script preparado**: Nunca improvisar
- [ ] **Código funcionando**: Todo debe correr perfecto
- [ ] **Ambiente limpio**: Desktop organizado
- [ ] **Audio test**: 30 segundos de prueba

#### **Durante Grabación:**
- [ ] **Hablar claro**: Pausas entre conceptos
- [ ] **Zoom apropiado**: Texto legible
- [ ] **Cursor visible**: Ayuda a seguir el código
- [ ] **Explicar mientras haces**: Narración continua

#### **Estructura de Video:**
1. **Intro** (30 seg): Qué vamos a hacer
2. **Concept** (2 min): Explicación teórica
3. **Demo** (8 min): Código en vivo
4. **Review** (2 min): Repaso de lo hecho
5. **Outro** (30 seg): Próximo video

### **🎬 Recomendaciones para Diseñadora:**

#### **Edición de Software:**
- **Aceleración**: Partes repetitivas 1.5x-2x
- **Zoom**: Acercar cuando sea necesario
- **Callouts**: Resaltar elementos importantes
- **Cuts**: Eliminar pausas largas

#### **Audio Processing:**
- **Noise Reduction**: Eliminar ruido de fondo
- **Normalization**: Niveles consistentes
- **EQ**: Realzar claridad de voz
- **Compression**: Dinámicas suaves

#### **Visual Enhancement:**
- **Color Correction**: Pantalla más vibrante
- **Contrast**: Mejorar legibilidad
- **Sharpening**: Código más nítido
- **Overlays**: Información contextual
