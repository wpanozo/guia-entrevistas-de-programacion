4. **Notes**: Edición específica needed

## 📝 Standards de Calidad

### **Video Specifications**:
- **Resolución**: 1920x1080 (Full HD)
- **Frame Rate**: 30 FPS
- **Codec**: H.264
- **Bitrate**: 8-10 Mbps
- **Color Space**: Rec. 709

### **Audio Specifications**:
- **Sample Rate**: 48 kHz
- **Bit Depth**: 24-bit
- **Format**: WAV (recording), MP3 (final)
- **Levels**: -12 dB peak, -18 dB average
- **Noise Floor**: Below -50 dB

### **Recording Standards**:
- **Room Tone**: 30 segundos al inicio
- **Sync Clap**: Para sincronización
- **Multiple Takes**: Mínimo 2 por sección difícil
- **Backup Audio**: Grabación redundante

## 🔄 Flujo de Post-Producción

### **Edición Diaria (2 horas/video)**

#### Workflow en Adobe Premiere Pro:
1. **Import & Sync** (15 min)
   - Video + audio sync
   - Color correction básica
   - Audio cleanup inicial

2. **Rough Cut** (45 min)
   - Removing mistakes
   - Basic transitions
   - Adding slides/graphics

3. **Fine Cut** (30 min)
   - Timing adjustments
   - Color grading
   - Audio level optimization

4. **Graphics & Effects** (30 min)
   - Lower thirds
   - Code highlighting
   - Transition effects

5. **Export & Upload** (20 min)
   - Render settings
   - Upload to cloud
   - Quality check

### **Batch Processing (Sábados)**
- **Color Grading**: Aplicar LUTs consistentes
- **Audio Normalization**: Levels consistency
- **Thumbnail Creation**: Batch design
- **Subtitle Generation**: Auto + manual review

## 💡 Tips Específicos Sony A6500

### **Configuraciones Óptimas**:
```
Picture Profile: PP6 (S-Gamut3.Cine/S-Log3)
ISO: 100-800 (sweet spot)
Shutter: 1/60s (180° rule)
Aperture: f/2.8-f/4 (depth + sharpness)
White Balance: Manual 5600K (LED lights)
Focus: Single AF + Manual fine-tune
```

### **Recording Settings**:
```

Quality: 50 Mbps
Frame Rate: 30p
Audio: Linear PCM
HDMI Output: Information Display Off
```
